# SignGlove World — نسخة أولية

## محتويات المشروع
- تطبيق Android بلغة Kotlin.
- اتصال Bluetooth Classic SPP مع ESP32 المتوافق.
- استقبال 9 قيم CSV بالترتيب: Flex1, Flex2, Flex3, AccX, AccY, AccZ, GyroX, GyroY, GyroZ.
- حفظ عينات تدريب محليًا على الهاتف.
- أقرب عينة محفوظة تُستخدم كتعرّف تجريبي.
- قاموس ترجمة محلي صغير بست لغات.
- نطق النص باستخدام Android TextToSpeech.

## مهم قبل الاستخدام
1. هذا نموذج أولي وليس مترجمًا جاهزًا أو نظامًا مدربًا على لغة الإشارة.
2. التعرف الحالي يقارن القراءات بأقرب عينة محفوظة فقط؛ لا يثبت صحة الإشارة ولا يفهم لغة الإشارة كاملة.
3. الكلمات الموجودة في القاموس محدودة جدًا. الترجمة العامة تتطلب خدمة ترجمة مستقلة.
4. يجب أن تكون لوحة ESP32 من الأنواع التي تدعم Bluetooth Classic SPP (مثل بعض لوحات ESP32-WROOM-32). بعض الطرازات مثل ESP32-S3 لا تدعم Bluetooth Classic SPP.
5. اقترني بلوحة ESP32 من إعدادات Bluetooth في الهاتف قبل فتح التطبيق.
6. يجب أن يرسل برنامج ESP32 سطر CSV يحتوي على 9 أرقام مفصولة بفواصل وينتهي بسطر جديد.
7. اختبري الدائرة والطاقة مع شخص بالغ لديه خبرة بالإلكترونيات، ولا توصلي بطارية LiPo أو وحدة الشحن قبل التحقق من القطبية والحماية ومواصفات الوحدات.

## بناء APK باستخدام الهاتف
يمكن بناء المشروع عبر GitHub Actions دون Android Studio على الهاتف:
1. أنشئي مستودعًا جديدًا على GitHub من المتصفح.
2. ارفعي جميع ملفات هذا المشروع مع الحفاظ على أسماء المجلدات.
3. افتحي تبويب Actions في المستودع.
4. اختاري workflow باسم `Build SignGlove World APK`.
5. اضغطي Run workflow وانتظري انتهاء البناء.
6. افتحي نتيجة التشغيل الناجح ونزّلي Artifact باسم `SignGloveWorld-debug-apk`.
7. فكّي ملف ZIP الناتج، ثم ثبتي `app-debug.apk` على هاتفك. قد يطلب Android السماح بالتثبيت من مصدر المتصفح/مدير الملفات.

هذه نسخة Debug للتجربة وليست إصدارًا منشورًا على Google Play.
